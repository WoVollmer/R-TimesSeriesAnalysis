# Climate Data Analysis and Corona Virus Dashboard

The **R-TimeSeriesAnalysis** folder provides R, Rmarkdown rsp. Quarto
(RMD/qmd) files for time series analysis.

See corresponding subfolders `Climate` and `Corona-Virus`.

## R code

My own R package `pkgTS` for TimeSeries Functions is hosted on GitHub
(https://github.com/WoVollmer/pkgTS) and can be downloaded using the
following command:

`pak::pak("WoVollmer/pkgTS")`

`library(pkgTS)`
